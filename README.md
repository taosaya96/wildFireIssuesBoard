# WildFire 问题/需求看板 (WildFire Issues & Requirements Board)

无尽战区(WildFire)问题登记 + 新功能需求看板。

- **index.html** — 单一 HTML 看板（双击浏览器打开即可，无依赖、无服务）
- **issues_board.md** — Markdown 数据源（与 HTML 内嵌数据同步）

## 使用方式

- 打开 `index.html` 查看问题登记与新功能需求
- 点击表头可排序（英雄 / 技能 / 编号 / 需求）
- 新问题/新需求由 AI 会话登记，刷新页面即可看到最新内容

## 状态图例

未修 → 诊断中 → 修复中 → 待复测 → 已修复 → 已放弃（官方如此/客户端数据不可改）
