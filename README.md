# 开源，让野火蔓延至永恒

无尽战区（WildFire）主题视觉页。整页只呈现这一句主题，不写别的文案。

- 背景：游戏内三张加载原画（主城 / 训练场 / 野火）自动轮播，也可手动切换
- 字体：游戏内 `ui/fonts/hkht.ttc` 提取的 DFHeiW7，搭配 Noto Serif SC 的重字重排版
- UI：游戏战斗播报特效里的红色徽记、横向光带与火焰序列帧，重做成 HUD 边框、六边形切换点和标题下的火线
- 动效：逐字入场、金属/火焰渐变、流光扫过、火星粒子、鼠标视差；支持 `prefers-reduced-motion`

## 打开

双击 `index.html` 即可，纯静态、无服务、无依赖。

## 操作

- 背景每 9 秒自动换一张；右下角三枚六边形可手动切换
- 键盘 `←` / `→` 切换背景
- 点击或触碰画面会溅起火星

## 文件

- `index.html` / `style.css` / `main.js`
- `assets/` — 游戏原画转出的 WebP、游戏 UI 特效、提取出的字体与红色菱形图标
- `issues_board.md` — 旧看板数据，保留备查；当前页面不再展示

旧看板页面已被本次设计替换，历史版本见 git 提交记录。
