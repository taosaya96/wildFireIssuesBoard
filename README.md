# WildFire 问题/需求看板 (WildFire Issues & Requirements Board)

无尽战区(WildFire)还原过程中发现的问题 + 新功能需求，统一记在这块看板上，双击 `index.html` 即可查看。

- **index.html** — 看板本体（纯静态页面，无依赖、无服务）
- **issues_board.md** — Markdown 数据源（与 HTML 内嵌数据同步）

## 使用方式

- 打开 `index.html` 查看问题登记与新功能需求；点击表头可排序（英雄 / 技能 / 编号 / 需求）
- 报问题或提需求，直接告诉 AI 会话即可——登记和状态流转都由它维护，刷新页面就能看到最新内容

## 状态流转

未修 → 诊断中 → 修复中 → 待复测 → 已修复 → 已放弃（官方如此/客户端数据不可改）
